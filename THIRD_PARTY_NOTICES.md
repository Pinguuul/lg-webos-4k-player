# Third-party components

The application uses the webOS media APIs supplied by the TV. No LG webOS SDK JavaScript, firmware, LG logos, or original template icons are included in this repository or its packaged app. The project icons were drawn specifically for this project.

The optional subtitle helper invokes separately installed FFmpeg and ffprobe executables; they are not bundled. Install and use those tools under their own licences. MiniDLNA/ReadyMedia, Node.js, Python and the webOS CLI are separate dependencies, not code relicensed by this project.

The MIT licence in this repository covers this project's original code and project icons. Development dependencies retain their upstream licences; see their installed package notices. Media files and subtitles are supplied by the user and are not distributed here.
